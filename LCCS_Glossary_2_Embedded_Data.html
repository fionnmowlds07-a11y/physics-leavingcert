🤖 Embedded & Physical Computing

Embedded System CORE

A computer system built into a larger device to perform a specific task, often with limited memory, power and user interface.

The computer inside a microwave, washing machine, or car's anti-lock brakes. It's not a general computer you use for browsing — it lives inside the device and does one job.

Microcontroller CORE

A small computer on a single chip used to control hardware such as sensors, LEDs and motors.

Micro:bit USEFUL

A small programmable microcontroller board used in schools for physical computing and embedded systems.

MakeCode EXTRA

A block-based and JavaScript coding environment commonly used with the micro:bit. Useful for embedded systems tasks in class, but not a core exam definition.

Sensor CORE

An input device that detects a physical quantity such as light, temperature, movement or moisture.

Your eyes are sensors — they detect light. A thermometer is a sensor that detects temperature. Sensors convert real-world information into data a computer can process.

Actuator CORE

An output device that causes a physical action, such as a motor, buzzer or servo.

Your muscles are actuators — they receive signals from your brain (the processor) and move. A motor, buzzer, or LED receives a signal and does something physical in the real world.

Digital Input CORE

An input with discrete states, usually on/off, 1/0, True/False.

Analogue Input CORE

An input that can vary continuously over a range, such as light level or temperature.

A dimmer light switch is analogue — it can be anywhere from fully off to fully bright. A regular on/off light switch is digital.

Digital Output CORE

An output signal with discrete states, often HIGH/LOW or on/off. Example: turning an LED on or off.

Analogue-to-Digital Conversion (ADC) USEFUL

The process of converting a continuous analogue signal into digital values a computer can process.

Pin USEFUL

A connection point on a microcontroller used to send or receive electrical signals.

🔌 Electronics Components

Circuit CORE

A complete path through which electric current can flow.

Like a closed loop of road — cars (current) can only travel if the road is continuous. Break the loop and traffic stops.

Voltage CORE

Electrical potential difference; a "push" that can cause current to flow in a circuit. Measured in volts (V).

Water pressure in a pipe. Higher pressure (voltage) pushes more water (current) through. No pressure = no flow.

Current CORE

The flow of electric charge in a circuit, measured in amperes (A).

Resistance USEFUL

Opposition to the flow of current, measured in ohms (Ω).

Resistor CORE

A component that limits current flow in a circuit, protecting sensitive components like LEDs.

Capacitor USEFUL

A component that stores electrical energy/charge and can release it.

Transistor CORE

A semiconductor component used as an electronic switch or amplifier; a basic building block of logic circuits and processors.

A transistor is like a tiny tap controlled by electricity. A small electrical signal at the tap handle controls whether a much larger current can flow. Billions of these microscopic "taps" make up a modern CPU.

Integrated Circuit CORE

A chip containing many electronic components/transistors on a single piece of semiconductor material.

Instead of soldering thousands of individual transistors onto a circuit board, an IC puts all of them on a piece of silicon the size of a fingernail — making computers small and cheap.

🚪 Logic Gates & Truth Tables

Logic Gate CORE

An electronic/computational component that performs a Boolean operation on one or more inputs to produce an output.

A logic gate is a tiny decision-maker made of transistors. It looks at its inputs and decides its output using a rule (AND, OR, NOT etc.).

Truth Table CORE

A table listing every possible input combination and the corresponding output of a Boolean expression or logic circuit.

Very common short question. Know AND, OR, NOT truth tables off by heart.

AND Gate CORE

Outputs 1/True only when all inputs are 1/True.

OR Gate CORE

Outputs 1/True when at least one input is 1/True.

NOT Gate CORE

Outputs the opposite of its input. Also called an inverter.

XOR Gate USEFUL

Outputs 1/True when inputs are different. Useful for half adders.

Half Adder USEFUL

A logic circuit that adds two binary bits and produces a sum and carry output.

Full Adder USEFUL

A logic circuit that adds two binary bits plus a carry-in, producing a sum and carry-out.

Pulse-Width Modulation (PWM) EXTRA

A way to simulate variable output by switching a digital signal on and off rapidly with different duty cycles. Used for LEDs/motors.

Like controlling light brightness by rapidly blinking a bulb on and off — the longer it stays on each cycle, the brighter it appears overall.

📂 Data Basics

Data CORE

Raw facts, values or observations that can be stored and processed by a computer.

A thermometer reading of "18" is data — just a number. On its own, it tells you little.

Information CORE

Data that has been processed or given context so it becomes meaningful.

"The temperature in Cork today is 18°C, which is 5°C warmer than average for May" — now it's information. Context has been added.

Dataset CORE

A collection of related data values, usually organised in records, tables or files.

Record CORE

A complete set of fields about one item/entity in a dataset or database table. In a table, a record is a row.

Field CORE

One category/attribute in a record, such as name, age or score. In a table, a field is a column.

Data Item USEFUL

A single value in a dataset, such as one person's age or one temperature reading.

CSV File CORE

Comma-Separated Values: a plain-text format where rows of data are stored line by line and fields are separated by commas.

Like a spreadsheet saved as plain text. Each row is a record, each comma separates a field. Very common for datasets — Excel, Python and databases can all open them.

JSON USEFUL

JavaScript Object Notation: a text-based data format using key-value pairs and lists, often used by APIs.

API USEFUL

Application Programming Interface: a way for one program/system to request data or services from another.

A waiter in a restaurant. You (your program) tell the waiter (API) what you want. The waiter goes to the kitchen (external service), gets it, and brings it back. You don't need to know how the kitchen works.

Open Data CORE

Data that is publicly available for people to use, reuse and share, often from governments or organisations.

🧹 Data Analytics & Cleaning

Data Analytics CORE

The process of collecting, cleaning, analysing and interpreting data to find patterns, answer questions or support decisions.

Hypothesis CORE

A testable prediction or proposed explanation that can be investigated using data.

"Students who sleep more than 8 hours get better exam results" — that's a hypothesis. You'd then collect data to test whether it's true.

Data Cleaning CORE

Finding and fixing/removing problems in data, such as missing values, duplicates, inconsistent formats or outliers.

Like proofreading an essay — you find typos (errors), missing sentences (missing values), and repeated paragraphs (duplicates), then fix them before submitting.

Validation CORE

Checking that input data is reasonable and follows rules before it is accepted or processed.

A website form that rejects your age if you type "200" or a negative number — it validates that the value makes sense.

Verification USEFUL

Checking that data has been entered or copied accurately from its source. Example: double entry or visual checking.

Missing Value CORE

A data item that is blank or absent when a value is expected.

Duplicate Record CORE

A repeated record that appears more than once in a dataset. Must be identified and removed during data cleaning.

Outlier / Anomaly CORE

A value that is unusual compared with the rest of the data and may be an error or a genuine exceptional case.

Do not automatically delete outliers without justification — they could be genuine data points worth investigating.

Inconsistent Format CORE

When similar data is written in different formats, such as dates recorded as "01/05/2024" in some rows and "May 1, 2024" in others.

📐 Statistics & Visualisation

Mean CORE

The arithmetic average: total of values divided by the number of values.

Median CORE

The middle value when values are sorted. If there are two middle values, the median is their mean.

Median = Meddle. Sort first, then find the middle.

Mode CORE

The most frequently occurring value in a dataset. Can be more than one mode.

Mode = Most Often. The value that appears most.

Range USEFUL

The difference between the highest and lowest values in a dataset.

Frequency CORE

The number of times a value or category occurs in a dataset.

Data Visualisation CORE

Representing data graphically, such as using bar charts, line graphs, pie charts or scatter plots.

Charts must have: title, axis labels (with units), and a legend where appropriate.

Bar Chart CORE

A chart using separate bars to compare categories or discrete values. Good for category comparisons.

Line Graph CORE

A chart using points connected by lines to show change over time or sequence. Good for trends over time.

Pie Chart USEFUL

A circular chart divided into sectors showing parts of a whole. Only use when parts sum to a meaningful whole.

Scatter Plot USEFUL

A chart showing points for pairs of values, useful for spotting relationships/correlation between two variables.

Axis Label CORE

Text that identifies what a chart axis represents and often its unit. Marks can be lost for unclear graphs.

Legend CORE

A key that explains colours/lines/categories in a chart. Use when a graph has multiple series.

Pandas USEFUL

A Python library used for data analysis and tabular data manipulation.

Matplotlib USEFUL

A Python library used to create charts and visualisations.

NumPy EXTRA

A Python library used for numerical computation and arrays. Useful for advanced analytics but not usually essential at LC level.

Seaborn / Plotly / Pygal EXTRA

Python visualisation libraries sometimes used for charts in coursework. Useful alternatives to Matplotlib but not required to memorise for the exam.
