📦 What is a Computer System?

A computer system is a combination of many connected parts all working together (interacting) to achieve a common goal.

Its purpose is simple: take in data → store it → process it → output results.

Think of a chef in a kitchen. Data comes in (ingredients), it's stored on the counter (memory), processed by cooking it (CPU), and the finished dish comes out (output). Every part works together!

The 4 Interactions in a Computer System:

ElementWhat it meansExample
HardwarePhysical, touchable componentsCPU, monitor, keyboard
SoftwarePrograms that run on hardwareWindows, Chrome, Word
DataInformation being processedYour name, a photo, a document
The UserThe person using the systemYou!

💾 Types of Software

Application software is software designed to allow users to complete a specific task. (e.g. Excel, Games)

System software provides a platform for application software to run on and manages the system's resources. (e.g. Windows, iOS)

Imagine a smartphone. The operating system (iOS/Android) is the system software — it's the foundation. The apps you download (Instagram, Maps) are application software — they sit on top of that foundation.

System software = Stage (the stage everything else performs on). Application software = Actor (performs a specific role on the stage).

🖥️ Types of Computer Systems

TypeDefinitionExample
General PurposeCan perform a wide range of tasksLaptop, desktop PC
Dedicated SystemDesigned to perform one specific functionWashing machine controller
Embedded SystemA system built into another system with a specific functionAutopilot in a car, smart thermostat

An embedded system is a system built into another system that has a specific function.

Your car has a computer built inside it that controls the airbags — that's an embedded system. You can't take it out and use it for something else. Compare that to your laptop (general purpose) which can browse the web, edit photos, or run games.

Know the difference between dedicated (standalone device for one job) and embedded (built inside another device). Exams love to test this distinction!

🏗️ Von Neumann Architecture

Von Neumann Architecture is a shared common architecture for computers described by John von Neumann in 1945. It consists of: Memory, CPU, Input/Output devices, and a Computer Bus.

Think of a house. Houses can look very different on the outside, but they all have common rooms: bedroom, bathroom, kitchen. Similarly, all computers look different but they all share the same core architecture: CPU, Memory, I/O, Bus.

Von Neumann Architecture — the universal computer blueprint

M-C-I-B — Memory, CPU, I/O, Bus — the four components of Von Neumann architecture.

RAM (Random Access Memory) — temporary memory that holds data and instructions of a program currently being executed by the CPU. Needs constant power to retain contents.

ROM (Read Only Memory) — non-volatile memory whose contents remain even when the computer is turned off. Cannot be written over. Used in BIOS.

RAM is like your desk — you put things on it while you're working, but when you go home (power off), everything gets cleared away. ROM is like a printed instruction manual — it's always there, you can read it, but you can't rewrite it.

RAM = Temporary, ROM = Permanent. RAM = Randomly Accessed Memory = things come and go. ROM = Really Only Memories = it's stuck there forever!

⚙️ The CPU & its Components

The CPU (Central Processing Unit) processes data and instructions, controls other components, and carries out computations.

Parts of the CPU:

The Control Unit directs the operations of the CPU.

It's the manager of the CPU — it doesn't do the actual work itself, it tells everyone else what to do and when.

The ALU (Arithmetic/Logic Unit) performs all arithmetic and logic operations. It receives instructions and data, and operates on the data according to the instructions.

The ALU is the calculator and decision-maker. It does maths (2+2=4) and logic (is 5 > 3? Yes!).

Registers are temporary storage locations inside the CPU that can be accessed very quickly. They are small in size but very fast.

A register is like a sticky note right in front of you — very small, but instantly accessible. RAM is like a filing cabinet in the next room.

RegisterFull NameWhat it does
PCProgram CounterStores the memory address of the next instruction to be executed
ACAccumulatorStores the output of the ALU (results of calculations)
MARMemory Address RegisterStores a memory address — points to a location in memory
MDRMemory Data RegisterTemporarily holds data of an instruction being transferred
CIRCurrent Instruction RegisterHolds the instruction currently being decoded/executed

Remember the registers with: "People Can Always Make Clever Inventions"
→ PC, CIR, AC, MAR, MDR

The Clock generates a continuous stream of electrical pulses at a stable frequency (measured in GHz). Each pulse activates one fetch-execute cycle. It ensures all circuits operate together at the right timing.

The clock is like a metronome for a musician — it keeps everything in perfect timing. The faster the metronome (higher GHz), the more notes you can play (instructions processed) per second.

The Bus connects the CPU and memory. It is a communication channel that carries data between internal components. USB stands for Universal Serial Bus.

The bus is like a motorway between cities (CPU and Memory). Data travels along it in both directions. A wider/faster bus = more data can travel at once.

🔄 The Fetch-Decode-Execute Cycle

This is how the CPU continuously runs programs. It's a loop that never stops while the computer is on.

The Fetch-Decode-Execute cycle is the continuous process by which the CPU retrieves a program instruction from memory, decodes it, and then executes it before fetching the next.

Fetch → Decode → Execute — the endless loop of the CPU

The Steps in Detail:

  1. 1The address of the next instruction is copied from the Program Counter (PC) to the Memory Address Register (MAR).
  2. 2The Program Counter increments — it now points to the next instruction (so it's ready for the next cycle).
  3. 3The instruction at the MAR address is copied to the Current Instruction Register (CIR).
  4. 4The Control Unit decodes the instruction in the CIR — it works out what needs to happen.
  5. 5The instruction is executed (carried out) — the ALU does any maths or logic needed.

F-D-E: "Food Doesn't Eat itself" → Fetch, Decode, Execute! The CPU has to Fetch food (instructions), Decode the recipe, then Execute the cooking!

🚀 Factors Affecting CPU Performance

FactorHow it affects performance
Clock SpeedFaster clock = more fetch-execute cycles per second = more instructions processed. Measured in GHz (billions of pulses/sec).
Number of CoresDual-core (2 cores) = 2 instructions simultaneously. Quad-core (4 cores) = 4 simultaneously. More cores = more parallel work.
Cache MemoryVery fast temporary memory located IN the CPU. More cache = CPU stores more instructions nearby = less waiting for RAM. Faster than RAM.

Clock speed = how fast one person works. Cores = how many people are working. Cache = how much stuff they have on their desk (vs. going to a filing cabinet = RAM).

In exams, for "explain how [factor] affects CPU performance" — you must say what the factor is and explain the direct impact. E.g. "More cache memory means the CPU can store more instructions nearby, reducing the time spent waiting to retrieve data from the slower RAM."

🖱️ Operating System (OS)

An operating system (OS) is a type of system software. It controls the general operation of a computer and provides an easy way for users to interact with a computer and run application software.

The OS is the manager of a building. It doesn't do the actual work (that's apps), but it makes sure the building has electricity (resources), the right people can enter (security), and everyone can find their office (file system).

🔌 BIOS & Startup Sequence

BIOS (Basic Input Output System) is stored in the ROM. It contains all the basic code for controlling computer hardware (keyboards, mice, monitors, hard drives). It runs at startup before the OS loads.

Startup Sequence (Step by Step):

  1. 1Power on → CPU fetches instructions from BIOS (stored in ROM). The small loader program in ROM sends instructions to load the OS.
  2. 2BIOS starts the monitor and keyboard; runs basic checks (e.g., looks for RAM).
  3. 3BIOS starts the boot sequence — it looks for the operating system on the hard drive.
  4. 4BIOS copies the OS from storage into RAM.
  5. 5BIOS transfers control to the operating system — your computer is now ready to use!

The BIOS is like a security guard who opens up a building every morning. It checks everything is working, then hands over to the office manager (OS) who runs the actual day-to-day operations.

Know the order: BIOS (from ROM) → checks hardware → loads OS from hard drive into RAM → transfers control to OS. You may be asked to put steps in order!

🎂 Layer Model of a Computer System

A Layered Structure is a type of computer system structure where the different services of the system are split into layers, and each layer has a specific, well-defined task to perform.

User ↔ Application Software ↔ Operating System ↔ Hardware

The Three Layers:

LayerRoleExamples
Application SoftwareWhere users interact to complete tasks. User gets direct output here.Word, games, music players
Operating SystemManages computer resources; bridge between apps and hardwareWindows, macOS, Linux, Android
HardwareLowest layer — physical components and peripherals. Cannot be directly accessed by user.CPU, keyboard, printer, scanner

Advantages of Layered Structure:

  • ✅ Modularity — each layer only does its own job
  • ✅ Easy debugging — errors can be traced to a specific layer
  • ✅ Easy updates — modifying one layer doesn't break others
  • ✅ No direct hardware access — users can't accidentally damage hardware
  • ✅ Abstraction — each layer doesn't need to know how other layers work

Disadvantages of Layered Structure:

  • ❌ Complex implementation — layers must be carefully ordered
  • ❌ Slower execution — requests must pass through multiple layers, increasing response time

Abstraction — each layer is only concerned with its own functions. The implementations of other layers are hidden (abstract) to it.

🧩 Computational Thinking

Computational thinking is a method of studying a problem and formulating a solution that can be carried out using a computer.

It's not about coding — it's about thinking. It's learning to break problems down the way a computer needs: clearly, logically, step by step, with no assumptions.

The 4 Pillars of Computational Thinking:

Abstraction — the process of filtering out characteristics not needed and focusing on those that are.

Decomposition — breaking down a complex task into smaller parts that are easier to understand and solve.

Pattern Recognition — finding similarities or patterns among decomposed problems to help solve more complex problems.

Algorithmic (Logical) Thinking — a way of getting to a solution by defining clear steps needed.

Remember the 4 pillars: A D P A — "A Dog Plays Around" = Abstraction, Decomposition, Pattern Recognition, Algorithmic Thinking

📜 What is an Algorithm?

An algorithm is a list of instructions — a set of well-defined, computer-implementable steps to solve a problem.

An algorithm is like a recipe. A recipe is a set of clear, step-by-step instructions to make a dish. An algorithm is the same — clear, ordered steps that a computer can follow to solve a problem. If a step is missing or unclear, the recipe (and program) fails!

The key word in the definition is "well-defined" — each step must be crystal clear, with no ambiguity. Exams may ask you to describe or evaluate an algorithm.

📊 Algorithmic Complexity & Big O Notation

Big O notation expresses algorithmic complexity — it defines the relationship between the number of inputs and the number of steps an algorithm takes to process those inputs.

⚠️ Big O is NOT about measuring speed — it's about measuring the amount of work a program does based on input size N.

Imagine searching for a name in a phone book. If the book has N names: Linear Search = worst case N steps. Binary Search = worst case log₂N steps. Big O tells you how the workload scales as N grows.

O(1)
⭐ BEST — Constant
No matter how big the input, always takes the same number of steps. E.g. accessing item at index [0] in an array.
O(log n)
✅ GOOD — Logarithmic
Steps grow very slowly as input grows. Binary Search is O(log₂n). Halves the problem each time.
O(n)
🟡 FAIR — Linear
Steps grow proportionally to input. Linear Search is O(n). Double input = double steps.
O(n log n)
🟠 BAD — Linearithmic
Worse than linear. Efficient sorting algorithms like Merge Sort fall here.
O(n²)
🔴 WORST — Quadratic
Steps = input². Bubble, Selection, Insertion Sort are all O(n²). 10 items = 100 steps, 100 items = 10,000 steps!
O(n!)
💀 TERRIBLE
Factorial — grows astronomically fast. Avoid at all costs for large inputs.

Best to Worst: 1, logn, n, nlogn, n², n!, nᶜ
Think: "1 log n-logn-n²-nightmare!" — each step is worse than the last.

Polynomial time complexities: O(n), O(n²), O(n³) — these grow as a power of n.

🔎 Search Algorithms

Linear Search — sequentially goes through each item in a list, comparing the target to each element. Returns the index if found, or -1 if not found.

Looking for your keys by searching every pocket, one by one, from start to finish. No shortcuts — you might find them at the start (lucky!) or at the very end (unlucky!).

Pros & Cons:

✅ Pros❌ Cons
Data does NOT need to be sortedSlow for large datasets — O(n) time complexity
Simple to implementAs list grows, comparisons grow linearly

Linear Search checks each item one by one until found (or end of list)

Binary Search — finds the middle of a sorted list, compares it to the target, and eliminates half the list. Repeats on the remaining half until found.

Looking for a word in a dictionary. You open it in the middle — if the word comes before, you only look in the first half. You keep halving the search area until you find it. Much faster than reading every word!

The Steps:

  1. 1Find the middle element of the sorted list.
  2. 2If middle < target → search the top (right) half.
  3. 3If middle > target → search the bottom (left) half.
  4. 4If middle = target → FOUND! Stop search.
  5. 5Repeat until found or list is empty.

Pros & Cons:

✅ Pros❌ Cons
Much faster — O(log₂n)Data MUST be sorted first
Efficient for large datasetsSorting has its own cost

Binary Search — halves the search area each time

Binary = TWO. Binary search always splits into TWO halves. It requires a sorted list — remember: "Binary Needs Sorted Books" (data must be ordered).

🔀 Sort Algorithms

All three sorting algorithms you need have a time complexity of O(n²) — they are inefficient for large datasets.

Selection Sort works by finding the smallest value in a list and placing it at the start, then finding the next smallest and placing it second, and so on, until the list is sorted.

Imagine sorting playing cards. You scan all cards to find the lowest, put it first. Scan the remaining cards for the next lowest, put it second. Repeat. Each "scan" takes n comparisons, and you do n scans = n² total.

How it works:

  1. 1Scan the whole list to find the minimum value.
  2. 2Swap it with the first element in the unsorted part.
  3. 3The first element is now sorted. Move the boundary forward.
  4. 4Repeat for the rest of the unsorted list.

Time complexity: O(n²) — loops n times, each requiring up to n comparisons.

Insertion Sort virtually splits the array into a sorted and unsorted part. Each element from the unsorted part is taken and inserted into the correct position in the sorted part.

Think of sorting a hand of playing cards. You pick up one card at a time and slide it into the right place in your already-sorted hand. Left side (sorted), right side (unsorted).

How it works:

  1. 1Start with the second element (first is considered already sorted).
  2. 2Compare it with elements before it one by one, moving backwards.
  3. 3Shift larger elements one position to the right to make space.
  4. 4Insert the current element into the correct position.
  5. 5Repeat for each element in the unsorted portion.

Time complexity: O(n²) — n passes with up to n comparisons each.

INSERTION = INSERT into sorted part. Like inserting a new card into your hand of cards in the right place.

Bubble Sort compares adjacent elements in an array and swaps them if they are in the wrong order. After each full pass, the largest unsorted element "bubbles" to its correct position at the end.

Like bubbles rising in a fizzy drink — the biggest bubble (number) always rises to the top (end of the array) first. After each pass through the drink, one more bubble settles at the top.

How it works:

  1. 1Start with the first adjacent pair of elements.
  2. 2Compare them — if out of order, swap them.
  3. 3Move to the next adjacent pair. Repeat for the whole array.
  4. 4After one full pass, the largest element is at the end (its final position).
  5. 5Repeat steps 1–4 until no more swaps occur.

Time complexity: O(n²) — very slow, almost never used in practice.

Optimisation:

Bubble sort can be made more efficient by counting swaps per pass. If swaps = 0 in a pass, the list is already sorted — stop the algorithm early!

BUBBLE = biggest value BUBBLES up to the top. After each pass, the END of the array is more and more sorted.

🌍 Internet vs. World Wide Web (WWW)

The Internet is the global network of connected computers that carries data (web pages, emails, files). It is hardware.

The World Wide Web (WWW) is a service that runs on top of the internet — it is the collection of web pages you view in a browser. The WWW is software/a service.

The internet is the road network — all the physical roads, motorways, and infrastructure. The WWW is one service that uses those roads (like delivery trucks). Email, FTP, etc., are OTHER services using the same road network.

Internet = Infrastructure (hardware). Web = Webpages (service running on that hardware). The web is a subset of what the internet does!

The WWW operates on a client-server model. Web pages are stored on web servers and each page has an address called a URL (Uniform Resource Locator).

🔗 URLs — Uniform Resource Locators

A URL (Uniform Resource Locator) is the unique address of a web page. It is also called the "web address".

📖 DNS — Domain Name Service

A DNS (Domain Name Service) converts human-friendly domain names (e.g. irishtimes.com) into machine-friendly IP addresses (e.g. 182.256.256.2).

DNS is like a phone book. When you want to call "Mum", your phone looks up "Mum" and finds the actual phone number (e.g. 086-123-4567). You don't need to remember the number — just the name. DNS does the same: you type "google.com" and DNS finds the IP address.

How DNS works (step by step):

  1. 1You type a URL (e.g. www.google.com) into your browser.
  2. 2Your Internet Service Provider (ISP) looks up the domain name using DNS.
  3. 3DNS finds the matching IP address and sends it back to you.
  4. 4Your browser sends a request directly to that IP address.
  5. 5The web server sends the webpage back to your browser using HTTP/HTTPS.

An IP address is a unique numerical label assigned to each device connected to a network. It allows devices to be located on the internet (e.g. 192.168.1.1).

DNS = Domain Name to IP. Like a translator between human language (google.com) and computer language (142.250.185.46).

📋 Communication Protocols

Protocols are a standard set of rules that computer systems follow to allow them to communicate, format, and process data.

Protocols are like the rules of a language. For two people to communicate, they need to agree on the same language (e.g. English), the same grammar, and how to take turns speaking. Protocols do the same for computers.

Protocols manage: speed of transmission, message size, error checking, and whether transmission is synchronous or asynchronous.

HTTP
HyperText Transfer Protocol
Transfers web pages between client browser and web server. Web pages are in hypertext format.
HTTPS
HTTP Secure
Secure version of HTTP. Data is encrypted during transfer — hackers can't intercept it. Used for banking, shopping, etc.
FTP
File Transfer Protocol
Transfers files between computers. Used for uploading/downloading files to/from a server.
SMTP
Simple Mail Transfer Protocol
Sends emails between mail servers.
VOIP
Voice Over Internet Protocol
Delivers voice and multimedia communications over the internet (e.g. Zoom calls).
TCP/IP
Transmission Control Protocol / Internet Protocol
The main protocol suite of the internet — breaks data into packets, routes them, and reassembles at the destination.

Know what each protocol stands for AND what it's used for. The exam often asks "What does HTTPS stand for and what is its purpose?" — know both parts!

📦 TCP/IP in Detail

TCP (Transmission Control Protocol) breaks data into equal-sized chunks called data packets, gives each a sequence number and check digit, reassembles them at the destination, and requests replacements for missing/corrupt packets.

IP (Internet Protocol) gives each device a unique IP address, encapsulates packets with a wrapper containing source and destination addresses, and routes packets across the internet.

Sending a large document by post: TCP = the person who splits the document into 10 envelopes, numbers them 1-10, and checks they all arrive. IP = the postal service that puts an address label on each envelope and routes them to the right destination. They work together!

🏢 Client-Server vs Peer-to-Peer Networks

In a client-server network, users work at client workstations. A server is a dedicated computer that stores data, manages resources, and controls access rights for all clients.

A school network is a great example. The server is like the school secretary — it has all the files, controls who can access what, manages logins, and assigns permissions. The classroom computers are clients — they connect to the secretary (server) to get what they need.

✅ Advantages❌ Disadvantages
More secure than P2PExpensive to buy and maintain
One client crashing doesn't affect othersServer failure disrupts ALL computers
Easier to administrate (managed centrally)May need a specialist network technician
Individual users don't worry about backups—

In a peer-to-peer (P2P) network, there is no central server. Each computer (called a peer) is equal and connected directly to other peers. No computer has control over another.

Imagine a group of friends sharing files directly between their phones — no central organiser, everyone just shares directly with everyone else. That's P2P!

✅ Advantages❌ Disadvantages
Users control their own filesEach computer needs its own backup
No cost of buying a serverPotentially less secure
Easier and cheaper to set upSecurity more expensive (each needs antivirus)
Peer failure only disrupts files from that peerFiles and resources harder to share

☁️ Cloud Computing

Cloud computing is the use of hardware and software to deliver services over the internet. Unlike LANs/WANs, you're not restricted to a local network — you can access your work and programs from anywhere you can get online.

Instead of keeping all your photos on your phone (local storage), you upload them to iCloud or Google Photos (cloud). They're now accessible from any device anywhere in the world — and someone else manages the servers that store them.

Types of Cloud Services:

IaaS (Online Data Storage / Infrastructure-as-a-Service) — businesses can purchase storage and processing power without physically buying or maintaining hardware. The cloud provider backs up the data to ensure it's never lost.

Example: AWS (Amazon Web Services), Microsoft Azure — companies rent server space instead of buying physical servers.

SaaS (Software Hosting / Software-as-a-Service) — instead of installing programs on each computer, software is hosted on cloud servers and downloaded when needed. A third-party provider keeps the software up to date.

Example: Microsoft 365, Google Docs — the software runs in the cloud, no installation needed.

Data Ownership & Privacy Concerns:

Cloud computing raises issues about data ownership. Using cloud services means sharing your data with a third-party provider. For this reason, government departments and banks often create their own private cloud servers because they have extra data protection requirements.

Cloud computing is a popular exam topic. Know the difference between IaaS and SaaS, and be able to discuss the advantages AND disadvantages — especially the data privacy issue for sensitive organisations.
